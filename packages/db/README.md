# @duskmarch/db

Подключение к PostgreSQL, миграции Drizzle и стартовые данные.

| Команда из корня   | Действие                                 |
| ------------------ | ---------------------------------------- |
| `pnpm db:generate` | создать SQL-миграцию по изменениям схемы |
| `pnpm db:migrate`  | применить миграции к `DATABASE_URL`      |
| `pnpm db:seed`     | записать стартовые данные (повторяемо)   |

## Новая таблица

1. Опишите её в `src/schema/<область>.ts`, добавьте экспорт в `src/schema/index.ts` и файл в
   `drizzle.config.ts`.
2. Выполните `pnpm db:generate`; проверьте и закоммитьте SQL вместе с `drizzle/meta`.
3. Применённые миграции не редактируются, исправление оформляется новой миграцией.

`duskmarch_dev` — данные разработчика. Интеграционные тесты очищают только `DATABASE_TEST_URL`
и отказываются работать с базой, имя которой не оканчивается на `_test`.
