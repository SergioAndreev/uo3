# Детерминированная среда

## Часы

`GameClock`: `now()` — игровое время в целых мс, `tick()` — `floor(now / tickMs)` (тик 50 мс), `utc()` — метка для журналов. В пределах тика чтения одинаковы.

- `SystemClock` — единственный модуль ядра, читающий системное время. `capture()` вызывается игровым циклом. Перевод UTC назад не влияет; скачок больше 250 мс обрезается и сообщается через `onDrift`.
- `FakeClock` (`@duskmarch/test-kit`) двигается только `advance` и `setTime`; движение назад — `ERR_CLOCK_REGRESSION`.

## ГПСЧ

`SeededRng` — `xoshiro128++`, состояние из сида через `splitmix32`, строковые сиды хэшируются FNV-1a по UTF-8. Эталонные векторы: `src/runtime/rng.vectors.json`, сгенерированы независимой реализацией.

| Метод | Назначение |
| --- | --- |
| `next()`, `float()` | 32-битное число, число в `[0, 1)` |
| `int(min, max)` | целое без смещения (отбраковка) |
| `roll('NdM+K')` | броски; ошибка — `ERR_INVALID_DICE` |
| `weighted`, `pick`, `shuffle`, `chance` | выбор и перемешивание |
| `fork(label)` | независимый поток, родитель не сдвигается |
| `snapshot()`, `SeededRng.restore()` | сохранение и восстановление |

Ядро не вызывает `Math.random`, `Date.now`, `new Date()`, `performance`, `process`, `window`, `document`: правило ESLint `@duskmarch/config/eslint/pure`.

## Игровое время и свет

1 игровой час = 240 000 мс (4 мин), сутки — 96 мин; `gameTime(nowMs, epochMs, gameHourMs)` возвращает сутки (с нуля), час и минуту.

Эйра всегда обращена к звезде, поэтому дня и ночи нет: свет плана качается. Фазы по минуте суток `p`: `ebb` (`p < 180` или `p ≥ 1 260`), `rise` (`< 540`), `crest` (`< 900`), `fall`. Уровень: `min + floor((max − min) × (720 − |p − 720|) / 720)`; Заря 25–85, Марь 10–50.
