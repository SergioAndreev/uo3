# Пространство мира

- **Клетка** — 1×1 м, `x, y ∈ 0..65 535`. **Высота** `h` — целые шаги по 0,25 м, `-1 024..1 023`.
- **Позиция** — план, `x`, `y`, `h`; объекты заморожены.
- **Планы:** Заря (`dawn`, 0) и Марь (`dusk`, 1) по 4096×4096, испытательный `proving` (255) 64×64. Профиль правил может зарегистрировать новые планы.
- **Сектор** — 16×16 клеток (пространственный индекс), **чанк** — 32×32 (данные мира, P02).

## Оси и направления

```
        север (0), −y
   7 (СЗ)     1 (СВ)
запад (6) ●  восток (2), +x
   5 (ЮЗ)     3 (ЮВ)
         юг (4), +y
```

Режим шага (`walk` или `run`) — отдельное поле. `directionTo` выбирает ось, если `1000·|меньшее смещение| ≤ 414·|большее|` (tan 22,5°), иначе диагональ.

## Камера и сцена

Поворот камеры `r ∈ 0..3` (по 90° по часовой). Экранное направление — `(d − 2r) mod 8`, обратное — `(s + 2r) mod 8`. Метры сцены: `X = x + 0,5`, `Y = h × 0,25`, `Z = y + 0,5`.

## Расстояния и зазоры

Чебышёв — для радиусов действия и интереса; есть квадрат евклидова и манхэттенское. Разные планы — `ERR_REALM_MISMATCH`. Рост героя 7 шагов (1,75 м), подъём за шаг до 2 шагов (0,5 м); значения переопределяет профиль.
