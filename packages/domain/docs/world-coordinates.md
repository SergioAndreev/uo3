# `domain/world-coordinates` — Координаты, фасеты, направления и изометрия

Модуль `@uo3/domain/coordinates` задаёт пространственную геометрию мира UO3 (ADR-003 / ADR-006 / ADR-007).

## Координаты и wire-форматы

- `Point2D`: целочисленные `x, y ∈ [0, 65535]` (`ERR_INVALID_COORDINATE`).
- `Point3D`: `Point2D` + знаковая высота `z ∈ [-128, 127]` (`ERR_Z_OUT_OF_RANGE`). Бинарная сериализация: ровно **5 байт BE** (`uint16 x`, `uint16 y`, `int8 z`).
- `WorldLocation`: `facet` (`uint8`) + `Point3D` в пределах карты. Бинарная сериализация: ровно **6 байт BE** (`uint8 facet`, `uint16 x`, `uint16 y`, `int8 z`).
- `Rect2D`: полуоткрытая область `[x, x + width) × [y, y + height)`. Партиции выравниваются кратно `16` тайлам (`ERR_UNALIGNED_PARTITION_BOUNDS`).

## Сектора `16×16` и блоки карт `8×8`

- `sectorX = Math.floor(x / 16)`, `sectorY = Math.floor(y / 16)`, 32-битный ключ `packSectorKey(sx, sy) = (((sy & 0xFFFF) << 16) | (sx & 0xFFFF)) >>> 0`.
- `blockX = Math.floor(x / 8)`, `blockY = Math.floor(y / 8)`, локальная ячейка `(y % 8) * 8 + (x % 8)`.

## Изометрическая проекция и зазоры

- Прямая проекция (`44×44 px`, `Z_STEP_PX = 4`): `screenX = (x - y) * 22`, `screenY = (x + y) * 22 - z * 4`, `baseDepth = x + y`.
- Обратная проекция при фиксированном `z`: `syAdj = screenY + z * 4`, `x = floor((syAdj + screenX) / 44)`, `y = floor((syAdj - screenX) / 44)`.
- Вертикальные константы: `PERSON_HEIGHT = 16`, `STEP_HEIGHT = 2`.
