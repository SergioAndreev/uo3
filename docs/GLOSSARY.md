# Глоссарий UO3

| Термин | Значение |
|---|---|
| **Шард (shard)** | Независимая копия игрового мира со своими аккаунтами-персонажами и базой данных |
| **Фасет (facet)** | Отдельная карта мира (Felucca, Trammel; позже Ilshenar и др.) |
| **Партиция** | Прямоугольная часть фасета, обслуживаемая одной `WorldPartitionRoom` |
| **Сектор** | Ячейка пространственного индекса 16×16 тайлов |
| **Тайл** | Клетка карты; land-тайл (земля) имеет высоты углов, static-тайл — объект статики |
| **Z** | Высота в мире (−128…127), 1 единица Z = 4 px на экране |
| **Serial** | 32-битный уникальный идентификатор сущности (мобайлы < 0x40000000 ≤ предметы) |
| **Mobile (мобайл)** | Живая сущность: игрок, NPC, существо |
| **Item (предмет)** | Любой не-мобайл объект: оружие, контейнер, дверь, мульти-деталь |
| **Multi (мульти)** | Составной объект из многих тайлов: дом, корабль |
| **Body** | Идентификатор модели тела мобайла (анимационный набор) |
| **Graphic / ItemID** | Идентификатор арта предмета/статики |
| **Hue (хью)** | Индекс палитры перекраски |
| **Layer** | Слот экипировки (OneHanded, Helm, Mount, Backpack, Bank …) |
| **Gump (гамп)** | Окно интерфейса UO; серверный гамп — окно, разметку которого задаёт сервер |
| **Paperdoll** | Окно персонажа с экипировкой |
| **Notoriety** | Статус репутации/атакуемости: Innocent (1, синий), Ally (2, зелёный), CanBeAttacked (3, серый), Criminal (4, серый), Enemy (5, оранжевый), Murderer (6, красный), Invulnerable (7, жёлтый) |
| **AOI / зона интереса** | Набор сущностей, видимых клиенту (радиус обновления) |
| **Intent (намерение)** | Сообщение клиента с запросом действия; сервер решает исход |
| **Game ticket** | Одноразовый короткоживущий токен входа в игровую комнату |
| **Era profile** | Набор констант и флагов функций конкретной эпохи UO |
| **Dirty-tracking** | Отметка изменённых сущностей для инкрементального сохранения |
| **Item ledger** | Журнал перемещений/созданий/удалений ценных предметов |
| **Handoff** | Передача игрока из одной комнаты (партиции/фасета) в другую |
| **Ghost-репликация** | Копия пограничных сущностей соседней партиции для бесшовной видимости |
| **IDOC** | «In Danger Of Collapsing» — состояние дома перед распадом |
| **Recall / Gate** | Заклинания телепортации по руне / открытия портала |
| **GM / персонал** | Сотрудник с уровнем доступа выше Player |
| **UOP / MUL** | Форматы архивов данных клиента UO (новый / старый) |
| **Cliloc** | Локализованная таблица строк клиента UO |
| **OPFS** | Origin Private File System — приватное хранилище браузера для кэша ассетов |
| **StateView** | Механизм Colyseus для фильтрации состояния под конкретного клиента |
