# Глоссарий Duskmarch

## Мир

| Термин | Значение |
| --- | --- |
| **Эйра** | Планета мира; всегда обращена к звезде одной стороной, жить можно в поясе сумерек |
| **План (`realm`)** | Область Эйры со своей картой и правилами: Заря (`dawn`, 0) и Марь (`dusk`, 1); испытательный `proving` (255) — только для тестов |
| **Заря** | Обжитые террасы, торговые города, PvP только по согласию |
| **Марь** | Руины и туманы, открытое PvP, полный лут, повышенная добыча |
| **Маяк** | Постройка для перехода между планами; игроки заправляют и содержат её |
| **Свет и Стужа** | Сезоны: качание оси сдвигает границу света, открывая и закрывая земли |
| **Цикл света** | Колебание освещённости плана в течение игровых суток: отлив, подъём, гребень, спад |
| **Игровые сутки** | 24 игровых часа; 1 игровой час = 4 реальные минуты |
| **Шард** | Независимая копия мира со своими аккаунтами, героями и базой данных |

## Пространство

| Термин | Значение |
| --- | --- |
| **Клетка** | Единица карты 1×1 м |
| **Высота (`h`)** | Целое число шагов по 0,25 м, −1 024…1 023 |
| **Сектор** | Ячейка пространственного индекса 16×16 клеток |
| **Чанк** | Ячейка данных мира 32×32 клетки |
| **Партиция** | Прямоугольник плана, кратный секторам, который обслуживает одна `WorldPartitionRoom` |
| **Направление** | Одно из восьми значений по часовой стрелке от севера (−y); режим шага — ходьба или бег — хранится отдельно |
| **Поворот камеры** | Один из четырёх фиксированных поворотов ортографической камеры по 90° |
| **Флаги клетки** | 32-битная маска свойств клетки: непроходима, закрывает обзор, опора, вода, глубина и др. |
| **Пакет ассетов** | Каталог с манифестом `pack.json`: модели, текстуры, звуки, палитра, чанки и индекс мира, каждая запись с хэшем и лицензией |
| **Чанк `DMCK`** | Собственный бинарный файл чанка мира: клетки (поверхность, оттенок, высота, флаги) и объекты |
| **Индекс мира** | `world.json` плана: размеры, сетка чанков с хэшами, ориентиры |
| **Ориентир** | Именованная точка или набор клеток синтетического мира, например испытательный стенд `stairs` |
| **Синтетический мир** | Детерминированно сгенерированный пакет для разработки и тестов (`proving`, `field`) |
| **Опора** | Высота, на которой можно стоять: пол клетки с флагом `standable` или вершина объекта-платформы |
| **Потолок** | Наименьшее основание препятствия над сущностью; вместе с ростом решает, помещается ли она |
| **Линия видимости** | Проверка, не закрывают ли клетки, объекты или рельеф луч от глаз источника к цели |
| **Патч мира** | Декларативный набор операций над клетками и объектами плана с базовой версией и обратным патчем |
| **Версия мира** | SHA-256 хэшей чанков плана; одинакова у всех узлов с одинаковыми данными |

## Сущности

| Термин | Значение |
| --- | --- |
| **Идентификатор сущности (`EntityId`)** | 32-битное число, вид в старших 3 битах; текстовая форма `I-6000002A` |
| **Герой** | Персонаж игрока (`hero`) |
| **Существо** | NPC, зверь, монстр (`creature`) |
| **Предмет** | Переносимый объект: оружие, инструмент, контейнер, ресурс (`item`) |
| **Постройка** | Составной объект: дом, корабль, маяк (`structure`) |
| **Маркер клиента** | Временный идентификатор предпросмотра (`ephemeral`), сервер его не принимает |
| **Каркас** | Тип телосложения существа: гуманоид, зверь, птица, водное, конструкт, огонёк |
| **Оттенок** | Индекс собственной палитры «янтарь — индиго», 0 — естественный цвет |
| **Палитра** | 256 оттенков: 15 тонов от янтаря до индиго по 17 ступеней яркости |
| **Ключ контента** | Строка `group.name` (например, `creature.ash-hound`), которой контент ссылается на модели и предметы |

## Герой и правила

| Термин | Значение |
| --- | --- |
| **Характеристики** | Мощь, Сноровка, Воля: каждая 10–120, сумма до 240 |
| **Ресурсы** | Здоровье, запал (выносливость), созвучие (магическая сила) |
| **Навык** | Одно из 36 умений, значение 0,0–100,0, сумма до 600,0 |
| **Школа** | Группа из шести навыков: Клинок, Охота, Ремесло, Созвучие, Путь, Общество |
| **Режим навыка** | `grow` — растёт, `keep` — не меняется, `yield` — уступает рост при общем капе |
| **Тон** | Основа магии: Жар, Стужа, Камень, Ветер, Свет |
| **Плетение** | Заклинание из двух-трёх различных тонов; стоимость зависит от местного баланса света и холода |
| **Репутация** | Нейтрален, союзник, нарушитель, изгой, враг |
| **Ополчение** | Стража Зари, пресекающая нарушения |
| **Контракт за голову** | Награда игроков за изгоя в Мари |
| **Профиль правил** | Набор констант, флагов функций и формул (`duskmarch`), переопределяемый на шарде |
| **Флаг функции** | Переключатель возможности в профиле: Марь, верховые животные, дома, мореходство, маяки, контракты |
| **Отпечаток профиля** | SHA-256 канонического JSON профиля; одинаков у клиента и сервера |

## Техника

| Термин | Значение |
| --- | --- |
| **AOI / зона интереса** | Сущности, которые видит клиент: радиус 20 клеток, крупные постройки — 32 |
| **Intent (намерение)** | Сообщение клиента с запросом действия; исход решает сервер |
| **Game ticket** | Одноразовый короткоживущий токен входа в игровую комнату |
| **Панель** | Окно интерфейса; серверная панель описывается JSON-схемой протокола |
| **Тик** | Шаг симуляции сервера, 50 мс |
| **Dirty-tracking** | Отметка изменённых сущностей для инкрементального сохранения |
| **Журнал предметов** | Запись создания, перемещения и удаления ценных предметов |
| **Handoff** | Передача героя из одной комнаты (партиции или плана) в другую |
| **Ghost-репликация** | Копия пограничных сущностей соседней партиции для бесшовной видимости |
| **Персонал** | Сотрудник с уровнем доступа выше `player`: helper, moderator, game-master, administrator, owner |
| **Уровень доступа** | `player < helper < moderator < game-master < administrator < owner`; старший уровень наследует разрешения младших |
| **Разрешение** | Право из таблицы `PERMISSIONS` (например, `world.edit`, `account.ban.temp`); неизвестное разрешение запрещено всем |
| **Эффективный уровень** | Уровень, с которым сотрудник играет сейчас (`eacl`); не выше назначенного (`acl`) |
| **Access JWT** | Подписанный Ed25519 токен доступа на 15 минут; открытые ключи — `/.well-known/jwks.json` |
| **Сессия (семейство refresh)** | Цепочка refresh-токенов одного входа; повторное предъявление использованного токена отзывает всю сессию |
| **Ограниченный токен персонала** | Access JWT с `scope: tfa_setup`: сотрудник без 2FA может только включить её или выйти |
| **Предыстория** | Готовый стартовый набор характеристик и навыков одной школы: Наёмник, Следопыт, Ремесленник, Созвучник, Странник, Посредник |
| **Стартовый город** | Точка появления нового героя: Ладь, Кремнёв, Соляр (Заря); на шарде разработки — испытательный лагерь |
| **Слот героя** | Место героя на шарде; число слотов задаёт шард, с дополнительными — не больше 7 |
| **Игровой билет** | Пара одноразовых токенов (комната партиции и хаб шарда) на 10–60 секунд; гасится игровым сервером |
| **Эпоха отзыва** | Метка времени: билеты аккаунта, героя или шарда, выданные не позже неё, больше не гасятся |
| **Heartbeat узла** | Запись игрового узла в Valkey раз в 5 секунд: онлайн, тик, дренаж; по ней каталог вычисляет статус шарда |
| **Outbox** | Таблица писем и событий, записанных в одной транзакции с изменением; доставляется с повторными попытками |
| **OPFS** | Origin Private File System — приватное хранилище браузера для кэша ассетов |
| **StateView** | Механизм Colyseus, фильтрующий состояние под конкретного клиента |
