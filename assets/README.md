# Ассеты

Допустимы собственные, CC0-1.0, CC-BY-4.0 и синтетические файлы (ADR-002). Данные других игр запрещены.

1. Формат: `.png`, `.webp`, `.glb`, `.ktx2`, `.ogg`, `.woff2`, не больше 512 КиБ.
2. Посчитайте `sha256sum <файл>`.
3. Добавьте в `ASSET_MANIFEST.json` запись `path`, `sha256`, `license`, `source`, `addedInPhase`.
4. Запустите `pnpm check:assets`.

| Код                        | Причина                               |
| -------------------------- | ------------------------------------- |
| `ERR_FORBIDDEN_ASSET_TYPE` | формат вне списка или чужая сигнатура |
| `ERR_BINARY_SIZE_LIMIT`    | файл больше 512 КиБ                   |
| `ERR_UNDECLARED_ASSET`     | нет записи или не совпал SHA-256      |
