# `@uo3/asset-tool`

Node 22 ESM CLI для валидации/инспекции клиентских файлов UO (BYOC, ADR-002) и генерации синтетического тестового мира (P02).

## Команды

```bash
pnpm --filter @uo3/asset-tool build
node apps/asset-tool/dist/index.js --version
node apps/asset-tool/dist/index.js check-env
pnpm --filter @uo3/asset-tool test:coverage
```
