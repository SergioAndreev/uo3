# `@uo3/admin`

Веб-консоль персонала UO3 (**React 19 + Vite 6**). В фазе P00 реализует валидацию `AdminEnvSchema`, рендер компонента из `@uo3/ui-kit`, защиту от утечки секретов и генерацию `dist/bundle-stats.json`.

## Команды

```bash
pnpm --filter @uo3/admin dev
pnpm --filter @uo3/admin build
pnpm --filter @uo3/admin test:coverage
```
