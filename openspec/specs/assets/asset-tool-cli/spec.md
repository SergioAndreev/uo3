# assets/asset-tool-cli Specification

## Purpose
Определяет команды `apps/asset-tool` для работы с пакетами ассетов и чанками мира: проверку, инспекцию, генерацию синтетического мира, превью плана и вычисление отпечатка.

## Requirements

### Requirement: Коды возврата и вывод
Каждая команда MUST завершаться кодом `0` при успехе, `1` при ошибках данных и `2` при ошибке вызова (неизвестная команда, отсутствующий аргумент). Флаг `--json` MUST переключать вывод в один JSON-объект на stdout; диагностика без `--json` SHALL выводиться на русском языке.

#### Scenario: Неизвестная команда
- **WHEN** запускается `asset-tool unpack`
- **THEN** код возврата `2`, вывод содержит список команд

### Requirement: Проверка пакета
Команда `validate-pack <каталог>` MUST проверять манифест и содержимое пакета по `assets/asset-pack`, а для чанков и индексов мира — по `assets/world-chunks`, и выводить все нарушения с кодами и ключами записей.

#### Scenario: Пакет с повреждённым чанком
- **WHEN** в сгенерированном пакете повреждён один чанк и запускается `validate-pack --json`
- **THEN** код возврата `1`, JSON содержит ошибку `ASSET_HASH_MISMATCH` с ключом этого чанка

### Requirement: Инспекция чанка
Команда `inspect-chunk <файл>` MUST выводить заголовок, статистику поверхностей и флагов, диапазон высот и список объектов чанка.

#### Scenario: Сводка чанка
- **WHEN** запускается `inspect-chunk --json` для чанка `(0, 0)` плана `proving`
- **THEN** вывод содержит `cx = 0`, `cy = 0`, `cells = 1024` и счётчики поверхностей, сумма которых равна `1024`

### Requirement: Генерация синтетического мира
Команда `generate-world --preset <proving|field> --seed <n> --out <каталог>` MUST создавать пакет `assets/synthetic-world` и отказываться перезаписывать непустой каталог без флага `--force`.

#### Scenario: Защита от перезаписи
- **WHEN** `generate-world` запускается с непустым каталогом без `--force`
- **THEN** код возврата `1`, файлы каталога не изменены

### Requirement: Превью плана и отпечаток
Команда `radar <каталог> --out <файл.png>` MUST строить PNG-превью плана (пиксель на клетку, цвет поверхности с затемнением по высоте), а `fingerprint <каталог>` — выводить отпечаток пакета.

#### Scenario: Размер превью
- **WHEN** запускается `radar` для пакета `proving`
- **THEN** создаётся корректный PNG 64×64 пикселя

#### Scenario: Отпечаток
- **WHEN** запускается `fingerprint --json` для пакета
- **THEN** вывод содержит 64 hex-цифры, равные отпечатку из `assets/asset-pack`
