# Спецификация: combat/damage-and-armor

## Purpose

Спецификация определяет детерминированный конвейер расчёта физического урона оружия с учётом характеристик и навыков (`Tactics`, `Anatomy`, `STR`, `Lumberjacking`), механику парирования щитом и оружием (`Parrying`), вероятностный выбор зоны попадания и поглощение урона доспехами (`Armor Rating`), потерю выносливости при ударах и износ прочности экипировки.

## ADDED Requirements

### Requirement: Базовый бросок урона оружия и бонусы характеристик
При успешном попадании сервер MUST вычислить базовый урон оружия броском `BaseDamage = rollDice(XdY) + Z` из паспорта предмета через сидируемый ГСЧ. К базовому урону сервер SHALL применить процентный бонус силы `StrBonusPct = floor(STR * 0.2)` (при `STR = 100` бонус составляет `+20 %`).

#### Scenario: Бросок базового урона алебарды с бонусом силы
- **WHEN** персонаж с `STR = 100` попадает алебардой с паспортным кубиком `2d23 + 3` (диапазон 5..49) и ГСЧ выбрасывает базовое значение `30`
- **THEN** сервер фиксирует `BaseDamage = 30` и рассчитывает вклад силы `StrBonusPct = 20 %` для суммирования в конвейере урона

#### Scenario: Детерминированность броска урона при фиксированном сиде ГСЧ
- **WHEN** в тестовом харнессе с фиксированным сидом `xoshiro128++` выполняется серия из 100 ударов одним и тем же оружием
- **THEN** последовательность значений `BaseDamage` побитово совпадает при каждом повторном прогоне симуляции

### Requirement: Модификаторы урона от навыков Tactics, Anatomy и Lumberjacking
Сервер SHALL вычислять масштабированный урон до брони по формуле:
`RawDamage = floor(BaseDamage * (Tactics + 50.0) / 100.0 * (100 + StrBonusPct + AnatomyBonusPct + LumberBonusPct) / 100)`, где `AnatomyBonusPct = (Anatomy == 100.0 ? 30 : floor(Anatomy * 0.2))`, а для оружия подкласса `Axe` дополнительно прибавляется `LumberBonusPct = (Lumberjacking == 100.0 ? 30 : floor(Lumberjacking * 0.2))` (для прочего оружия `LumberBonusPct = 0`).

#### Scenario: Полный бонус грандмастера с топором и Lumberjacking
- **WHEN** персонаж с `STR = 100`, `Tactics = 100.0`, `Anatomy = 100.0` и `Lumberjacking = 100.0` выбрасывает `BaseDamage = 30` двуручным топором `Executioner's Axe`
- **THEN** сервер применяет множитель `Tactics` `1.5` (`30 * 1.5 = 45`) и суммарный бонус `+80 %` (`+20 % STR + 30 % Anatomy + 30 % Lumberjacking`), получая `RawDamage = floor(45 * 1.8) = 81`

#### Scenario: Штраф урона при нулевом навыке Tactics
- **WHEN** персонаж с `Tactics = 0.0`, `STR = 50` (`+10 %`), `Anatomy = 0.0` и мечом выбрасывает `BaseDamage = 20`
- **THEN** сервер масштабирует базовый урон множителем `(0 + 50) / 100 = 0.5` и бонусом силы `1.1`, получая `RawDamage = floor(20 * 0.5 * 1.1) = 11`

### Requirement: Парирование щитом и оружием по навыку Parrying
Если у защищающегося экипирован щит, сервер MUST до расчёта брони проверить шанс парирования `ParryChance = floor(Parrying / 2) %` (до 50 %); для двуручного оружия ближнего боя без щита — `floor(Parrying / 4) %` (до 25 %). При успешном парировании щитом урон уменьшается на `ParryAbsorb = floor(ShieldAR * (50 + Parrying / 2) / 100)` для ближнего боя и на `floor(ParryAbsorb / 2)` для стрел/болтов, а также запускается проверка прокачки `Parrying`.

#### Scenario: Парирование удара ближнего боя щитом при GM Parrying
- **WHEN** по персонажу с щитом (`ShieldAR = 24`) и `Parrying = 100.0` проходит удар мечом с `RawDamage = 40`, и срабатывает 50 % шанс парирования
- **THEN** сервер поглощает щитом `floor(24 * 100 / 100) = 24` ед. урона, оставляя `16` ед. для дальнейшего расчёта по броне, и помечает удар флагом `parried = true`

#### Scenario: Уполовиненная эффективность парирования щитом против выстрела из лука
- **WHEN** тот же персонаж с `ShieldAR = 24` и `Parrying = 100.0` успешно парирует стрелу с `RawDamage = 30`
- **THEN** щит поглощает только половину стандартного значения `floor(24 / 2) = 12` ед., передавая `18` ед. на этап расчёта брони

### Requirement: Выбор зоны попадания и расчёт эффективного класса брони
Для каждого не заблокированного полностью удара сервер SHALL выбрать зону попадания по взвешенной таблице вероятностей: `Body/Chest` (44 %), `Arms` (14 %), `Head` (14 %), `Legs` (14 %), `Neck` (7 %), `Hands` (7 %). Эффективный `ZoneAR` элемента доспеха в выбранной зоне MUST масштабироваться текущей прочностью предмета `ZoneAR = floor(BaseItemAR * CurrentHP / MaxHP)`, а сводный `TotalAR` в окне статуса — как взвешенная сумма всех зон плюс бонус щита.

#### Scenario: Выбор зоны попадания и учёт износа кирасы
- **WHEN** бросок ГСЧ зоны попадания (0..99) попадает в диапазон `0..43` (`Body/Chest`), где надета кираса с `BaseItemAR = 40` и прочностью `CurrentHP = 25 / MaxHP = 50`
- **THEN** сервер выбирает зону `Body/Chest` и вычисляет её актуальный рейтинг защиты `ZoneAR = floor(40 * 25 / 50) = 20`

#### Scenario: Попадание в незащищённую зону при частичном комплекте брони
- **WHEN** персонаж носит только кирасу и поножи, а бросок зоны попадания выпадает на `Head` (диапазон `58..71`), где шлем отсутствует
- **THEN** сервер использует для данного удара `ZoneAR = 0` независимо от общего `TotalAR` персонажа

### Requirement: Поглощение физического урона бронёй и финальный урон
Сервер MUST вычислять поглощение бронёй выбранной зоны как случайное целое число `ArmorAbsorb = randomInt(floor(ZoneAR / 2), ZoneAR)`, вычитать его из урона после парирования и делить остаток пополам: `FinalDamage = max(1, floor((PostParryDamage - ArmorAbsorb) / 2))` (если удар не был полностью поглощён до `<= 0` бронёй/щитом; при полном поглощении `FinalDamage = 0`).

#### Scenario: Расчёт финального урона после поглощения доспехом
- **WHEN** после этапа парирования остаётся `PostParryDamage = 50`, в зоне попадания `ZoneAR = 30`, и ГСЧ поглощения выбрасывает `ArmorAbsorb = 20`
- **THEN** сервер вычисляет `floor((50 - 20) / 2) = 15`, списывает `15 Hits` у цели и рассылает `CombatDamageEvent (amount = 15)`

#### Scenario: Полное поглощение слабого удара тяжёлым доспехом
- **WHEN** `PostParryDamage = 10`, а бросок поглощения доспеха с `ZoneAR = 36` даёт `ArmorAbsorb = 22`
- **THEN** остаток урона `10 - 22 <= 0`, сервер фиксирует `FinalDamage = 0` и не уменьшает `Hits` защищающегося

### Requirement: Потеря выносливости при получении урона и прерывание действий
При любом попадании с `FinalDamage >= 1` сервер SHALL уменьшать текущую выносливость `Stam` цели на `floor(FinalDamage / 15)` единиц, а при попадании дробящим оружием (`Mace Fighting`) — дополнительно на `randomInt(2, 5)` единиц `Stam` и удваивать урон по прочности брони цели. Любой `FinalDamage >= 1` MUST прерывать активное чтение заклинаний и сдвигать/сбивать перевязку бинтами согласно правилам P16.

#### Scenario: Дополнительное сжигание выносливости от дробящего оружия Mace Fighting
- **WHEN** атакующий с булавой (`Mace Fighting`) наносит цели `FinalDamage = 30`, а дополнительный бросок сжигания выносливости даёт `4`
- **THEN** сервер списывает у цели `30 Hits` и `floor(30 / 15) + 4 = 6 Stam`

#### Scenario: Удар с нулевым уроном не сбивает активное действие цели
- **WHEN** удар по цели полностью поглощён щитом и бронёй (`FinalDamage = 0`)
- **THEN** сервер не списывает `Stam` у цели и не прерывает её текущие действия

### Requirement: Износ, поломка и разрушение оружия, щитов и доспехов
При каждом попадании сервер SHALL с вероятностью 4 % уменьшать текущую прочность `CurrentHP` атакующего оружия, щита (при парировании) и поражённого элемента брони на `1` (на `2` для брони при ударе `Mace Fighting`). При падении `CurrentHP` до `0` предмет MUST немедленно разрушаться с удалением из слота экипировки, записью в `item_ledger` и уведомлением владельца `ERR_COMBAT_ITEM_DESTROYED`.

#### Scenario: Потеря единицы прочности доспеха при попадании
- **WHEN** удар попадает в зону `Body`, и 4 % бросок износа срабатывает на кирасе с `CurrentHP = 10`
- **THEN** сервер уменьшает `CurrentHP` кирасы до `9`, пересчитывает `TotalAR` персонажа и помечает предмет для dirty-flush

#### Scenario: Полное разрушение оружия при падении прочности до нуля
- **WHEN** меч с `CurrentHP = 1` наносит удар, и срабатывает 4 % шанс потери прочности
- **THEN** сервер удаляет меч из слота руки, записывает причину `COMBAT_BREAKAGE` в `item_ledger`, переводит персонажа на `Wrestling` и отправляет уведомление о поломке оружия

### Requirement: Аудит и телеметрия боевого урона
Сервер SHALL формировать структурированный результат каждого боевого разрешения (`CombatResolutionRecord`), содержащий `attackerSerial`, `defenderSerial`, `weaponSerial`, `hitChance`, `rawDamage`, `parryAbsorb`, `hitZone`, `armorAbsorb`, `finalDamage` и `specialMove`, и экспортировать агрегированные метрики урона и числа замахов в минуту в Prometheus/OTel.

#### Scenario: Запись детальной структуры разрешения удара для отладки и тестов
- **WHEN** сервер завершает расчёт попадания в `SimulationTestHarness` или боевой комнате
- **THEN** формируется полный `CombatResolutionRecord` со всеми промежуточными значениями конвейера и обновляются счётчики телеметрии `uo3_combat_swings_total` и `uo3_combat_damage_total`

#### Scenario: Отображение всплывающего числа урона на клиентах в AOI
- **WHEN** цель получает `FinalDamage = 24`
- **THEN** сервер рассылает `CombatDamageEvent` наблюдателям в AOI, а клиент отрисовывает всплывающее число `24` над головой цели
